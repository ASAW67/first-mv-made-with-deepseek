# sunset.py — 5 秒日落

> 没有任何素材：没有照片、没有贴图、没有视频片段、没有音效采样。
> 天空、云、太阳、海、波纹、草、鸟、环境声，全部由 `numpy / opencv / Pillow` 现场算出来。

**成片**：`out/sunset_5s_4K60.mp4` — 3840×2160 / 60fps / 5.000s / 300 帧 / 95 MB / AAC 48k 立体声
**静帧**：`out/sunset_still_4K.png`（3840×2160）、`out/sunset_still.png`（1920×1080）

---

## 1. 一次渲染分两层

| 层 | 分辨率 | 内容 | 为什么 |
|---|---|---|---|
| 氛围层 | **半分辨率** | 天空渐变、太阳与日冕、云、光轴、远岛、海面、日光带、地平线雾 | 天光本来就是柔的，半分辨率反而**没有色带**，还把最贵的一步砍掉 4 倍 |
| 结构层 | 全分辨率 | 前景草叶、礁石、飞鸟、镜头暗角 | 这些是硬边剪影，一定要锐 |

氛围层算完用 `kit.up()` 放大、`kit.blur()` 轻微柔化，再叠结构层——观众看到的是「镜头虚化」，不是「低分辨率」。

## 2. 每一块是怎么来的

- **天空**：8 段色阶查表（`_ramp`）——深靛 `0A1730` → 紫 `3A2A5E` → 珊瑚 `A84A5C` → 橙 `DA663F` → 金 `FFC96B`，全部按 `y/地平线` 取。
- **太阳**：`core`（硬边圆盘）+ `limb`（临边昏暗，边缘比中心暗 40%）+ 三层 `halo`。**关键**：氛围层返回的是 **HDR（0–6 不截断）**，圆盘值 ≈ 2.6、圆盘外 ≈ 0.9，最后统一 `tonemap_soft`——如果在中途 `clip(0,1)`，圆盘会和它自己的光晕一起被压成同一个白色，太阳就"消失"了（这一步踩过）。
- **云**：两层不同尺度的 fBm 值噪声（横向拉长 5 倍）→ 阈值化成密度 → 乘三条高斯高度带。**迎光边缘**用「当前点密度 − 朝太阳方向偏移 9px 处的密度」求差分，于是每朵云的朝日一侧自己亮起来。
- **薄云挡太阳**：不做「变灰」，而做**前向散射**——`f *= 1 - body*0.82*(1-0.88*veil)`，同时 `f += sun_color*body*veil*1.9`。所以太阳被云扫过时会「透出一团亮」，而不是变成一个灰点。
- **光轴**：`atan2(y-sy, x-sx)` 取角度 → `sin(26θ)` 取幂 → 乘径向衰减，被云密度遮挡（`1-dens*0.85`）。
- **海面**：竖向反照色阶；波纹用 `sin(9.4/(y+0.055))`——**频率随距离压缩**，这就是透视；再加一层横向噪声让条纹起伏、被 `streak` 噪声切碎成一截一截。日光柱 `exp(-|x-sx|/colw)` 上窄下宽，只有波峰（`crest`）反光。
- **前景草叶**：沿二次贝塞尔曲线取法线，做**两端粗细不同**的多边形（`blade()`），宽 20–32px 收到 1px；颜色 `05070C`，只在朝太阳的一侧留 1px 暖色轮廓光；极前景两片大叶用 `blur(3.2*S)` 做景深。
- **飞鸟**：7 段线，翅膀角度 `sin(7.2t + i*1.35)`，越远越小越慢。
- **摄影机**：5 秒里推近 1.4%、横移 0.4%——**几乎察觉不到，但没有它画面就是死的**。
- **环境声**：三段不同周期的涌动（2.35s / 3.71s / 1.43s）调制白噪声，FFT 分带塑形 → 低频浪吼 90–620Hz + 浪花 500–2600Hz + 空气感 3.2–11kHz + 风 220–900Hz，双声道用不同种子去相关，头 0.4s / 尾 1.1s 淡入淡出。没有一处采样。

## 3. 调色链

```
HDR 合成 → tonemap_soft(1.05) → tone(exposure 1.02, contrast 1.08, sat 1.07, gamma 0.97)
        → 暗部偏青 / 亮部偏暖的 split-tone
        → 摄影机推近
        → bloom(thresh 0.70, radius 30, strength 0.42)
        → vignette 0.30 → grain 0.016（每帧不同种子，所以有真实的胶片呼吸）
```

## 4. 命令

```bash
python sunset.py --still 2.6                     # 一张 1080p 静帧
python sunset.py --times 0.0,2.6,4.9 --scale 1   # 多帧拼图 sunset_sheet.png
python sunset.py --video --scale 2 --workers 8   # 300 帧 4K60 成片
```

实测（32 核 / 16 GB）：4K 单帧 1.6–2.6 s，8 进程 300 帧 **357 秒**，编码 crf 18 后 95 MB（159 Mbps——颗粒和波纹都是高频，压不动）。
